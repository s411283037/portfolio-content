# 給網站開發 Codex 的內容交接

此包只整理內容與規格，沒有網站程式、沒有部署。

## 讀取順序
1. AGENTS.md、docs/design-spec.md。
2. README.md、content/profile.yaml、content/skills.yaml。
3. content/education、experience、certifications、projects 中各檔。
4. docs/pending-items.md、docs/assets-manifest.yaml。

## 網頁用法
- 個人開場／About 使用 profile；學經歷分組讀各資料夾。
- 首頁三個精選依 order：饗賓、yoxi、CheckMate。屬本次內容包建議初始排序，可由使用者調整。
- camp-cooking 為已可呈現的其他案例，可在專案區補一個文字入口；草稿不可由首頁連出。
- 所有 title 保留正式中文名稱；大區塊可用 About／Experience／Projects／Skills & Credentials／Contact。
- 案例正文依使用者七題模板，正式排版可縮短為「背景／貢獻／判斷／行動／成果／反思／證據」，不可改變意思或遺漏個人貢獻邊界。
- status: published 是內容可進預覽及正式輸出的狀態，不代表網站或外部發布已完成；目前仍未部署。
- 未知日期 null，不把 null 轉成今天或至今；正在進行僅依 ongoing。
- public 素材為空。不輸出空框、待補字樣、虛構圖或下載連結；待補列表只是維護文件。
- 外部 Demo／Canva 來自既有作品集，這次未重新測試連線或閱覽權限，交付前應實測並移除無法訪客使用的入口。
- 尚未部署、不推送 Git；先完成本機可瀏覽預覽與適用檢查。
